# TensoraMax Studio: Example Prompts for TXB

This document provides a collection of example prompts that users can utilize to interact with TXB, the AI assistant within TensoraMax Studio. These examples demonstrate TXB's capabilities across various modules and tasks, from code generation to creative assistance.

## Web Development Prompts

### HTML

*   "Generate a basic HTML5 boilerplate with a linked CSS file and a JavaScript defer script." 
*   "Create an HTML structure for a responsive navigation bar with a logo on the left and three menu items on the right." 
*   "Add a contact form to this HTML page with fields for name, email, subject, and message." 
*   "Explain the purpose of the `<meta name="viewport">` tag in HTML." 
*   "How do I embed a YouTube video responsively in HTML?" 

### CSS

*   "Write CSS to center a `div` both horizontally and vertically using Flexbox." 
*   "Create a CSS animation for a button that changes its background color and scales up slightly on hover." 
*   "Provide CSS for a dark mode theme, primarily changing background and text colors." 
*   "Explain the difference between `margin` and `padding` in CSS." 
*   "How can I make an image responsive in CSS without distorting it?" 

### JavaScript

*   "Write a JavaScript function to validate an email address using a regular expression." 
*   "Create a simple JavaScript counter that increments by one every second and displays the value on the page." 
*   "How do I fetch data from a REST API endpoint using `async/await` in JavaScript?" 
*   "Explain the concept of closures in JavaScript with an example." 
*   "Write a JavaScript snippet to add an event listener to a button that displays an alert when clicked." 

## UI/UX Design Prompts

*   "Suggest a color palette for a tech startup website that conveys innovation and trustworthiness." 
*   "Provide feedback on this dashboard layout for a project management tool. Is it intuitive?" 
*   "Generate three alternative icon designs for a 'save' action." 
*   "Explain the principles of Gestalt psychology and how they apply to UI design." 
*   "How can I improve the accessibility of this web form for users with visual impairments?" 

## AI Assistant Interaction Prompts

*   "Summarize the key features of the TensoraMax Studio Video Editor module." 
*   "What are the main differences between the `web-static` and `web-db-user` project scaffolds?" 
*   "Help me brainstorm ideas for a new feature in the Code Editor that uses AI to suggest code optimizations." 
*   "Explain the concept of 'contextual awareness' as it applies to TXB." 
*   "What are the planned future enhancements for TXB in the Labs module?" 

## Project Planning Prompts

*   "Break down the task of 'developing a new user authentication system' into smaller, manageable sub-tasks." 
*   "Suggest a timeline for a 3-month web development project, including design, frontend, backend, and testing phases." 
*   "What are the critical success factors for launching a new AI-powered mobile application?" 
*   "Help me write user stories for a feature that allows users to export video projects in multiple formats." 
*   "Provide a checklist for the deployment phase of a full-stack web application." 

These examples illustrate the diverse range of tasks TXB can assist with, encouraging users to explore its capabilities through natural language interaction.
